# NANTA
### Brief Description
This is a notetaking application created by others and myself, allowing users to create, edit, retrieve, and delete notes once they are registered and logged in. 
Users also have the ability to customize their profile information.

## Installation
``` bash


#Clone into repo and make working directory
git clone
cd mern-group4

#Install dependencies
npm install
```
## Usage
``` bash


#Activate the backend
cd backend/
npm run dev

#Activate the frontend
cd ../frontend
npm run dev 
```
## Features
- User authentication (register and login)
- Create, save, edit, and delete notes
- Integrated Pomodoro Timer
- Profile Customization
- Dark Mode
